Tile it. Nest it. Zoom it.

Tileception is a Wayland compositor for Linux. Windows sit side by side in a tree of tiles, and you zoom between its levels instead of digging through a stack.

Scroll to zoom in.

Free and open source.
Written in Rust on Smithay. Xwayland included.

Tile it.

Open a window and it takes half of the focused tile, split along the longer side. No dragging, no empty space to fill by hand.

Super+J flips a split between rows and columns. Drag a gap to resize.

Super+T
terminal

Super+B
browser

Super+E
files

Nest it.

Splits go inside splits, as deep as you like. Drag a window onto a tile's edge to dock it there, onto its centre to make a tab group.

Super+G groups selected windows into tabs.

Or float it.

Want one window on top after all? Super+V lifts it above the layout. Press it again to dock.

  3. 3 · again, insideSplits nest. Zoom into any of them.

Zoom it.

Super+= steps in toward the focused window and Super+- steps back out. Or hold Super and scroll to zoom in toward the pointer.

You've been doing this for three levels now.

Run it.

It runs as your login session, or in a window on your current desktop while you try it. One monitor for now. HiDPI and fractional scaling work.

Xwayland

X11 programs tile like everything else, with the clipboard shared both ways.

Launcher

Tap Super on its own. Notifications and a power menu are built in too.

Lock & capture

Super+L locks with your wallpaper. Print saves a screenshot. grim and swaylock work as well.

One config file

config.toml is reloaded on save. Script it with tileception msg.

Get it.

Alpha. 0.x releases are unstable and may break between versions. 1.0 will be the first stable one.

On Debian 13 / sid or Ubuntu 24.04 / 26.04:

curl -fsSL https://tileception.space/install | sh

Rather build it yourself? Clone the repository and run ./install-session.sh, then pick Tileception on the login screen.
