Tileception

This is Ubuntu's installer, set up to install Tileception. Write the ISO to a USB stick, start the computer from it and choose Install. The installer downloads Tileception and its apps as it goes, so the computer needs internet.

Try Ubuntu, the other choice on the stick, starts Ubuntu's usual desktop. You get Tileception after installing.

Write it to a USB stick

Use a stick of 8 GB or more. The easiest way is Ventoy: set up the stick with it once, which erases it, then copy the ISO onto it like any other file.

On a Mac, or if Ventoy gives you trouble, write the ISO to the stick with any USB writing tool, such as balenaEtcher.

Check the download

The checksums are signed with the same key as Tileception's packages:

curl -fsSLO https://tileception.space/download/SHA256SUMS
curl -fsSLO https://tileception.space/download/SHA256SUMS.gpg
curl -fsSL https://apt.tileception.space/tileception.gpg -o tileception.gpg
gpgv --keyring ./tileception.gpg SHA256SUMS.gpg SHA256SUMS
sha256sum -c --ignore-missing SHA256SUMS

Already on Ubuntu or Debian?

Keep your system and add Tileception with one command. For the apps and services that come with the ISO, run sudo apt install tileception-desktop afterwards.
